# Fabula (Фабул) — бинарные релизы / Binary releases

Официальная бинарная дистрибуция Android-приложения «Фабул» (аудио-метод Исаева). Исходный код здесь не публикуется — в Releases только подписанные APK.

English: official binary distribution of the Fabula Android app. No source code here — signed APKs only.

## Установка / Install
Скачайте APK из последнего релиза или через приложение: Настройки → Обновления.
Download the APK from the latest release, or use the in-app updater.
